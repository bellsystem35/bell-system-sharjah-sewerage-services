## 4. قواعد الربط والتحسين في WordPress

1. صفحة خدمة الشفط الرئيسية تشير إلى **دليل المناطق** و**وايت صرف صحي** و**البيارات والخزانات** حسب حاجة الزائر.
2. دليل المناطق يربط بصفحات المناطق الاثنتي عشرة مباشرة، مع وصف صغير يشرح متى تختار كل صفحة.
3. صفحة المنطقة توضح نوع العقار وأعراض المشكلة وطرق الوصول بصورة متفردة؛ المقال الداعم يجيب سؤالًا آخر بدل إعادة صياغة طلب الخدمة.
4. المقال الداعم الذي يشرح سبب الامتلاء يربط بصفحة شفط المجاري الرئيسية وبالدليل المناسب، دون إكثار الروابط المتطابقة في كل فقرة.
5. صور WebP تستخدم بنصوص alt تصف المحتوى المرئي؛ لا نضع عنوان الخدمة الطويل نفسه في جميع الصور.
6. لا يُضاف `H1` ثانٍ داخل HTML محتوى WordPress إذا كان قالب الصفحة يعرض H1 تلقائيًا؛ وهذا لا ينطبق على عناوين Markdown هنا.
7. تُراجع روابط canonical وsitemap والفهرسة من أدوات WordPress وSearch Console؛ تغيير روابط WordPress أو إعدادات noindex لا يحدث من خلال تعديل GitHub.
8. لا ينبغي ملء WordPress بـ12 نسخة نصية متشابهة لمجرد وجود أسماء مناطق؛ الأفضل محتوى مختلف له قيمة محلية حقيقية وموثق.

## 5. ما يحتاج مراجعة مستقبلية ببيانات Search Console

- هل تتنافس صفحة الخدمة ID 132 مع صفحة البيارات ID 296 على الاستعلام نفسه؟ لاحظ فرق نية الشراء والشرح العام.
- هل تتنافس صفحة وايت ID 1206 مع ID 132؟ احتفظ بموضوع مميز يتناول السيارة والوصول.
- هل تحصل الصفحات المحلية على انطباعات منفصلة لاستعلامات المنطقة؟
- هل توجد أخطاء soft 404 أو صفحات مستبعدة أو canonical مختار مختلف عن المقصود؟
- هل هناك صفحات منخفضة القيمة تحتاج إلى تحسين أو دمج؟ لا تحذف قبل فحص أدائها وروابطها الحالية.

**مهم:** لا يعني نشر مستودع GitHub عام أن Google سيفهرسه بالضرورة أو أن صفحة WordPress ستترتب أعلى. القيمة تأتي من تحسين الصفحة الرسمية وتجربة الزائر وصدق المعلومات والروابط المناسبة.

## حالة عنقود المناطق بعد تحسين 6 أكتوبر 2026

أصبحت صفحات المناطق الاثنتا عشرة في WordPress جميعها تتجاوز تقريبًا 3,000 كلمة بعد التحسين، مع بقاء وظيفة كل صفحة محلية ومحددة بنوع العقار والوصول والسياق التشغيلي في منطقتها. لا يغيّر ذلك خريطة النية الأساسية:

- **ID 132** يبقى صفحة الطلب التجاري الرئيسية لخدمة شفط المجاري في الشارقة.
- **ID 2514** يبقى دليل اختيار المنطقة.
- صفحات المناطق الاثنتا عشرة تستهدف سياق المنطقة ونوع العقار والوصول، ولا ينبغي تحويلها إلى نسخ من الصفحة الأم.
- المقالات تبقى طبقة معلوماتية للتشخيص والاستعداد والمتابعة.
- GitHub يبقى طبقة توثيق مساندة، وليس مجموعة صفحات هبوط بديلة.

في الفحص الأخير لمحتوى WordPress المخزن لم تظهر وسوم H1 أو style أو script داخل صفحات المناطق الاثنتي عشرة، وكانت الصور الموجودة WebP، مع وجود روابط ثابتة للصفحة الأم والدليل والهاتف وواتساب.

### تعديلات التنفيذ

- أضيف إلى **ID 132** مركز قرار يربط مباشرة بدليل المناطق وصفحة الوايت وصفحة البيارات والخزانات ودليل اختيار نوع الخدمة.
- أضيف إلى **ID 296** قسم تقني يوضح الفرق بين السعة والرواسب ومعدل الامتلاء، مع صورة WebP رسمية ومراجع إلى مقالات التشخيص وتكرار الامتلاء.
- أضيف إلى مقال **ID 3871** عن سيارات الشفط رابط مباشر إلى صفحة الوايت **ID 1206** لتأكيد أن المقال معلوماتي وأن صفحة الوايت هي مرجع الخدمة المتعلقة بالمركبة والوصول.
- لم يُحذف أو يُدمج أي مقال متقارب النية لعدم توفر بيانات Search Console اللازمة لاتخاذ قرار دمج آمن.

في الفحص بعد الحفظ لم تظهر وسوم H1 أو style أو script جديدة في الصفحات المعدلة.
