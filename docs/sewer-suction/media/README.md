## قواعد الاستخدام

1. أدرج الصورة عندما توضح نقطة مرتبطة بالمقال أو المنطقة.
2. استخدم نصًا بديلًا وصفيًا مختصرًا؛ تجنب سرد كلمات مفتاحية.
3. لا تقدم صورة توضيحية على أنها دليل موثق على تنفيذ عملية معينة.
4. لا تستخدم صورة منطقة معينة مع عنوان منطقة أخرى إلا إن كان الوصف عامًا ومعلنًا أنه توضيحي.
5. لا تكرر نفس الصورة لمجرد زيادة عدد الصور.
6. روابط الصور خارجية إلى الموقع الرسمي وتحتاج إلى استمرار استضافة المصدر.
7. جميع الصور أعلاه امتدادها WebP ومسجلة بوسائط الموقع الرسمي بصيغة image/webp.
