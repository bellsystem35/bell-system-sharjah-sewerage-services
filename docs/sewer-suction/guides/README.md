## مسار سريع

- **فيلا + بيارة ممتلئة:** ابدأ بدليل الفلل ثم صفحة منطقتك.
- **برج أو بناية + عدة وحدات متأثرة:** ابدأ بدليل البنايات ثم صفحة المنطقة.
- **مصرف واحد بطيء:** اقرأ الفرق بين الشفط والتسليك.
- **امتلاء يعود بسرعة:** اقرأ أسباب الامتلاء السريع والطفح المتكرر.
- **مشكلة تتكرر في نفس الخط:** راجع دليل متى قد يفيد فحص الكاميرا.
