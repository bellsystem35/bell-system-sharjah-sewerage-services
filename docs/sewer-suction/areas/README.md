# دليل مناطق شفط مجاري الشارقة | BELL SYSTEM

هذا الفهرس يساعد على اختيار صفحة المنطقة المناسبة داخل توثيق BELL SYSTEM لخدمة شفط المجاري.

## مناطق يغلب عليها سياق الفلل والبيارات

- [السيوح](al-suyoh.md) — فلل، ملاحق، مسار خرطوم داخل الحوش.
- [الرحمانية](al-rahmaniya.md) — فلل ومجمعات سكنية وتنسيق الوصول.
- [القرائن](al-qarayen.md) — فلل وأجزاء متعددة من المنطقة.
- [النوف](al-nouf.md) — فلل وبيارات قريبة أو بعيدة عن البوابة.
- [حوشي](hoshi.md) — فلل ومجالس وملاحق.
- [كشيشة](kshisha.md) — عقارات قد تضم أكثر من نقطة تجميع.

## مناطق يغلب عليها سياق الأبراج والبنايات

- [المجاز](al-majaz.md) — أبراج وبنايات وغرف تجميع مشتركة.
- [الخان](al-khan.md) — مبانٍ متعددة الوحدات ومحال.
- [النهدة](al-nahda.md) — بنايات ومواقف وغرف مضخات.
- [التعاون](al-taawun.md) — أبراج وتنظيم دخول مع إدارة المبنى.
- [القاسمية](al-qasimia.md) — بنايات ومحال ونقاط خدمة مشتركة.
- [مويلح](muweilah.md) — مزيج من بنايات ومجمعات وفلل ومواقع تجارية.
