# خريطة نية البحث — Sewer Suction Cluster

هذه الوثيقة تمنع تداخل الصفحات وتوضح وظيفة كل نوع من المحتوى.

## 1. الصفحة المركزية

**docs/sewer-suction/README.md**

النية: فهم خدمة شفط المجاري في الشارقة والانتقال إلى المنطقة أو الدليل المناسب.

لا يجب أن تتحول هذه الصفحة إلى نسخة من صفحة WordPress الرسمية.

## 2. صفحات المناطق

النية: معلومات محلية مرتبطة بنوع العقار والوصول ونقطة التجميع.

### فلل وبيارات
- السيوح
- الرحمانية
- القرائن
- النوف
- حوشي
- كشيشة

### بنايات وأبراج ومجمعات
- المجاز
- الخان
- النهدة
- التعاون
- القاسمية
- مويلح

كل صفحة منطقة يجب أن تحتوي على عناصر محلية أو تشغيلية مختلفة فعلًا، لا مجرد تغيير اسم المنطقة.

## 3. الأدلة المعلوماتية

- الفرق بين الشفط والتسليك
- البيارة مقابل خزان أو غرفة تجميع
- شفط مجاري الفلل
- شفط مجاري الأبراج والبنايات
- المطاعم والمطابخ التجارية
- أسباب الطفح المتكرر
- الامتلاء السريع بعد الشفط
- ماذا ترسل قبل وصول السيارة
- السلامة عند طفح مياه الصرف
- متى تحتاج إلى فحص كاميرا

## 4. قواعد منع التعارض

- لا ننشئ صفحة جديدة لمجرد اختلاف كلمة مثل "وايت شفط" و"سيارة شفط" و"شفط بيارات" إذا كانت النية واحدة.
- لا نكرر نفس المقدمة والخاتمة في 12 منطقة.
- لا نجعل GitHub نسخة مطابقة للموقع الرسمي.
- الربط يكون من المركز إلى المناطق والأدلة، ومن كل صفحة إلى المركز ودليل مناسب.
- الموقع الرسمي هو المرجع الأساسي للخدمة والحجز.

## 5. الهدف

وضوح البنية للمستخدم ومحركات البحث، وتقليل cannibalization والتكرار، وبناء شبكة روابط منطقية بدل صفحات كثيفة الكلمات المفتاحية.
