## مبادئ الاستخدام

1. استخدام أصول BELL SYSTEM الموجودة في مكتبة WordPress فقط.
2. اختيار صورة تطابق الفعل أو السياق: بالوعة حمام، مصرف مطبخ، مصرف خارجي أو فحص صرف محلي.
3. عدم استخدام صور الشفط كصورة أساسية لتنظيف البالوعة ما لم يكن السياق يشرح الفرق بين الخدمتين.
4. alt يصف الصورة بصورة طبيعية ولا يُستخدم لحشو الكلمات المفتاحية.
5. الصور غير الأساسية تستخدم `loading="lazy"` عندما يكون ذلك مناسبًا.
6. لا توجد حاجة لإنشاء صور جديدة لمجرد زيادة العدد إذا كانت الصفحة تحتوي أصولًا مناسبة بالفعل.
