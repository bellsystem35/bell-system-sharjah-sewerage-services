# Media Plan — تنظيف بالوعات المجاري

## الهدف

استخدام صور أصلية وخفيفة بصيغة WebP مع alt وصفي طبيعي، من دون نصوص داخل الصور أو حشو كلمات مفتاحية.

## الحالة الحالية

- ID 105: أربع صور داخل المحتوى وكلها WebP.
- ID 1080: أربع صور داخل المحتوى وكلها WebP.
- القرائن ID 2356: أربع صور WebP.
- السيوح ID 2358: ثلاث صور WebP.
- عدة صفحات مناطق أخرى تحتوي صورًا قديمة ليست WebP أو لا تحتوي صورًا داخل المحتوى.

## مجموعة الصور المطلوبة

1. تنظيف بالوعة حمام مع إزالة شعر/رواسب من المصفاة.
2. تنظيف مصرف مطبخ مع دهون قريبة من فتحة الصرف.
3. تنظيف بالوعة أرضية في فيلا.
4. فحص بالوعة قبل تحديد هل المشكلة تنظيف أم تسليك.
5. تنظيف مصرف في مبنى/مرفق مشترك.
6. صورة معدات يدوية مناسبة للتنظيف الموضعي.
7. لقطة بعد التنظيف تظهر فتحة نظيفة بلا نصوص.
8. صور محلية للمناطق عند توفر أصول أصلية حقيقية.

## Alt text

يصف المشهد وما يظهر فعلًا. مثال:
`تنظيف بالوعة أرضية من الرواسب في فيلا بالشارقة`

لا تستخدم alt مثل:
`أفضل شركة تنظيف بالوعات رخيصة رقم واحد...`
