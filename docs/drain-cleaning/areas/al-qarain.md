## النية المحلية

فلل ومجالس وملاحق؛ رواسب موضعية مقابل عائق داخل المسار.

## حدود الصفحة

هذه الصفحة تستهدف **تنظيف بالوعات المجاري في القرائن**. لا ينبغي أن تصبح نسخة من صفحة تنظيف البالوعات الرئيسية ID 105، ولا أن تنافس صفحة تسليك البالوعات ID 1080 أو صفحة تسليك المجاري ID 114.

## مسار القرار

- أوساخ ورواسب قريبة من فتحة المصرف → تنظيف البالوعة.
- عائق داخل مسار بالوعة محددة → تسليك البالوعة ID 1080.
- عدة نقاط مترابطة أو رجوع مياه بينها → تسليك المجاري ID 114.
- ارتفاع منسوب بيارة أو خزان → شفط المجاري ID 132.
