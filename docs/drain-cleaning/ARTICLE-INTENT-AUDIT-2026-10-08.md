## قاعدة الربط

المقال الذي يتحدث عن تنظيف الرواسب القريبة يدعم ID 105. المقال الذي يتحدث عن عائق داخل مسار البالوعة يدعم ID 1080. المقال الذي يتحدث عن عدة نقاط مترابطة يدعم ID 114. لا تدفع مقالات الروائح أو الشفط إلى ID 105 لمجرد ذكر كلمة "بالوعة".

## قرار الدمج

لا تُدمج المقالات المتشابهة قبل مراجعة بيانات Search Console على مستوى الاستعلام والصفحة.


## تغييرات التنفيذ بعد التدقيق

- ID 723 كان بعنوان قريب جدًا من الصفحة التجارية الأم. تم تحويل عنوانه ووظيفته إلى **متى يكفي تنظيف البالوعة ومتى تحتاج إلى تسليك؟** مع إبقاء URL القديم وعدم حذفه قبل مراجعة Search Console.
- ID 721 كان قريبًا من نية دليل المناطق. تم تحويله إلى **كيف تختار صفحة تنظيف البالوعات حسب منطقتك؟** ليشرح استخدام الدليل ID 2374 بدل منافسته.
- المقالات 2390 و2392 و3656 و1044 و3654 و196 و2380 أصبحت تحتوي Router واضحًا إلى:
  - ID 105 لتنظيف البالوعات.
  - ID 1080 لتسليك البالوعة.
  - ID 114 لتسليك الخط.
  - ID 132 للشفط عند ارتفاع المنسوب.
- المنتج ID 2973 بقي صفحة طلب/تحويل قصيرة، وتم ربطه بالصفحة الأم والدليل وصفحات التسليك بدل توسيعه إلى صفحة تجارية مكررة.

## إشارة البحث العامة بعد التنفيذ

البحث العام في 8 أكتوبر 2026 أظهر أن مقالات مثل تنظيف بالوعات الحمامات ودليل الرواسب وصفحات مناطق مثل القرائن ومويلح والرحمانية قابلة للاكتشاف في نتائج الويب، لكن بعض اللقطات المفهرسة/المزحوفة ما زالت قديمة بأيام أو أسابيع. لذلك لا ينبغي الحكم على التغييرات المنشورة اليوم قبل إعادة الزحف، ويجب تأكيد الأداء من Google Search Console.
