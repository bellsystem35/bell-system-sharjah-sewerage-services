# SEO Intent Map — تنظيف بالوعات المجاري في الشارقة

## الهدف

منع تداخل نية البحث بين تنظيف البالوعات، تسليك البالوعات، تسليك الخط، الضغط المائي والشفط.

## الصفحات المركزية

| ID | الصفحة | النية الأساسية | لا ينبغي أن تنافس |
|---:|---|---|---|
| 105 | تنظيف بالوعات في الشارقة | تنظيف الرواسب والأوساخ القريبة من فتحة المصرف | تسليك البالوعة أو الخط |
| 2374 | دليل مناطق تنظيف البالوعات | اختيار المنطقة | الصفحة الأم على الاستعلام العام |
| 1080 | تسليك بالوعات المجاري | عائق داخل مسار بالوعة محددة | التنظيف الدوري |
| 114 | تسليك مجاري | عدة نقاط أو فرع/خط مشترك | تنظيف بالوعة واحدة |
| 1077 | تسليك بالضغط | تنظيف أعمق للخط بعد التقييم | التنظيف الموضعي |
| 132 | شفط المجاري | ارتفاع منسوب داخل نقطة تجميع | مشاكل البالوعة أو الخط |

## خريطة القرار

1. **ترسبات ظاهرة أو أوساخ حول فتحة مصرف واحد** → ID 105.
2. **المصرف بطيء بعد تنظيف الجزء الظاهر** → ID 1080.
3. **تشغيل نقطة يسبب رجوع الماء من نقطة أخرى** → ID 114.
4. **انسداد متكرر/ترسب ممتد بعد تقييم الخط** → قد يدعم ID 1077.
5. **عدة مرافق بطيئة بسبب امتلاء بيارة أو خزان** → ID 132.
6. **استعلام محلي "تنظيف بالوعات + المنطقة"** → صفحة المنطقة عبر ID 2374.

## الصفحات المحلية

صفحات المناطق الاثنتا عشرة تستهدف سياق المنطقة ونوع العقار والمطبخ/الحمام والمصارف المحلية. لا يجب تحويلها إلى نسخ من ID 105.

## المقالات

- مقالات تنظيف الحمامات والمطابخ والرواسب → تدعم ID 105.
- مقالات علامات انسداد البالوعة والبطء → تدعم ID 1080 أو ID 114 حسب نطاق المشكلة.
- مقالات الفرق بين الخدمات → تعمل كصفحات تشخيص وتوجه إلى الصفحة الصحيحة.
- مقالات الروائح → تبقى في عنقود الروائح إلا عندما تكون الرواسب في البالوعة جزءًا حقيقيًا من المشكلة.
- مقالات الشفط والطوارئ → تبقى في عناقيدها.

## الدمج

لا يتم حذف أو دمج URL لمجرد تشابه الكلمات. القرار يحتاج Search Console لمعرفة الاستعلامات والصفحات التي تظهر فعليًا، والنقرات والظهور ومتوسط الموضع والـcanonical المختار.
