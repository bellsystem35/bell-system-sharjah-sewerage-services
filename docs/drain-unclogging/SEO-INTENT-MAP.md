# SEO Intent Map — تسليك المجاري في الشارقة

## الهدف

منع تداخل نية البحث بين صفحات BELL SYSTEM الخاصة بالتسليك والضغط وتنظيف البالوعات والشفط.

## الصفحات المركزية

| ID | الصفحة | النية الأساسية | ما يجب ألا تنافسه |
|---:|---|---|---|
| 114 | تسليك مجاري في الشارقة | فتح انسداد خطوط الصرف العامة | صفحة الضغط أو البالوعات أو الشفط |
| 2494 | دليل مناطق التسليك | اختيار صفحة المنطقة | الصفحة الأم على الاستعلام العام |
| 1077 | تسليك بالضغط | ضغط مائي وتنظيف أعمق للخط بعد التقييم | التسليك العام |
| 105 | تنظيف بالوعات | رواسب وأوساخ قريبة من فتحة المصرف | انسداد الخط |
| 1080 | تسليك بالوعات | عائق داخل مسار بالوعة محددة | تنظيف دوري أو خط مشترك |
| 1368 | باقة تسليك المجاري | طلب/منتج/تحويل تجاري | المحتوى التفسيري للصفحة الأم |

## قاعدة اختيار الخدمة

1. **نقطة واحدة + أوساخ قرب الفتحة** → ID 105.
2. **نقطة واحدة + عائق داخل مجرى البالوعة** → ID 1080.
3. **عدة نقاط مرتبطة أو رجوع مياه بينها** → ID 114.
4. **ترسبات ممتدة/عودة الانسداد والحالة مناسبة للضغط** → ID 1077 بعد التقييم، لا تلقائيًا.
5. **ارتفاع منسوب خزان أو بيارة أو غرفة تجميع** → عنقود شفط المجاري، لا التسليك.
6. **نية جغرافية** → صفحة المنطقة عبر ID 2494.

## صفحات المناطق

الصفحات المحلية تستهدف "تسليك مجاري + المنطقة" وتضيف سياقًا حقيقيًا بحسب نوع العقار وتوزيع الخطوط والوصول. لا ينبغي أن تعيد كتابة تعريف الخدمة العام الموجود في ID 114.

## المقالات

- مقالات **علامات الانسداد، التشخيص، ماذا تفعل، أسباب الانسداد** تدعم ID 114.
- مقالات **الرواسب القريبة والبالوعات والمصارف** تدعم ID 105 أو ID 1080 حسب عمق المشكلة.
- مقالات **الانسداد المتكرر والتنظيف الأعمق** يمكن أن تدعم ID 1077 عندما يكون الضغط مناسبًا بعد التقييم.
- المقالات المحلية تدعم صفحة المنطقة المناسبة.
- مقالات الروائح والشفط والطوارئ تبقى في عناقيدها ولا تُجبر على تمرير السلطة إلى التسليك.

## قرارات الدمج

تشابه العناوين لا يكفي لحذف أو دمج URLs. أي قرار دمج يحتاج بيانات Google Search Console لمعرفة الاستعلامات والصفحات التي تظهر فعليًا، والنقرات والظهور ومتوسط الموضع والـ canonical المختار.
